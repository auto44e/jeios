# Mobile scaffold moved

The authoritative fresh-kernel mobile scaffold is now in
[auto44e/jeios-mobile](https://github.com/auto44e/jeios-mobile).

The owner explicitly superseded the AOSP/Linux host proposal on 2026-10-13.
Mobile uses the fresh C JeiOS kernel; AOSP is a reference and future Android app
compatibility layer across the ecosystem. See [MOBILE.md](../../docs/MOBILE.md).
No duplicate kernel or mobile scaffold is maintained in this directory.
